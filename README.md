# F1 Lap Analysis

This is a small Python project I made to practise reading CSV files and working with data.

It reads a fictional F1 lap-time CSV file and calculates each driver’s fastest lap and average lap time.

It also finds the overall fastest lap in the dataset.

The main file is `f1_lap_analysis.py`.

The example data is in `sample_lap_data.csv`.

To run it:

```bash
python f1_lap_analysis.py
```

The lap times are fictional.

This is a beginner project, not a real Formula 1 data-analysis tool.
